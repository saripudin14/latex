\chapter{KESIMPULAN DAN SARAN}

\section{Kesimpulan}
Berdasarkan hasil pengembangan Sistem Informasi Peminjaman Sarana dan Prasarana Kampus Berbasis Web Menggunakan CRUD RDBMS, dapat disimpulkan bahwa:
\begin{enumerate}
    \item Sistem berhasil mendukung proses pengelolaan peminjaman dan inventaris sarana dan prasarana kampus secara terkomputerisasi dan terintegrasi.
    \item Penerapan konsep CRUD dan RDBMS memungkinkan pengelolaan data inventaris, pengguna, dan transaksi peminjaman dilakukan secara terstruktur dan terdokumentasi dengan baik.
    \item Metode Scrum efektif digunakan dalam pengembangan sistem karena mendukung proses iteratif, evaluasi berkala, dan penyesuaian kebutuhan pengguna.
    \item Sistem menyediakan fitur utama meliputi pengelolaan inventaris, pengajuan peminjaman, verifikasi peminjaman, verifikasi kehadiran, serta laporan peminjaman.
    \item Hasil Black Box Testing menunjukkan seluruh fungsi utama sistem berjalan sesuai kebutuhan, dan pengujian code coverage membuktikan modul inti sistem telah diuji dan berfungsi dengan baik.
\end{enumerate}

\section{Saran}
Adapun saran untuk pengembangan sistem selanjutnya adalah sebagai berikut:
\begin{enumerate}
    \item Menambahkan fitur monitoring kondisi dan riwayat penggunaan inventaris untuk mendukung manajemen aset kampus.
    \item Meningkatkan cakupan unit testing agar persentase code coverage dapat lebih optimal pada seluruh modul sistem.
    \item Memperkuat aspek keamanan dan audit log untuk meningkatkan keandalan dan pelacakan perubahan data sistem.
\end{enumerate}
