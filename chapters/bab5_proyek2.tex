\chapter{KESIMPULAN DAN SARAN}

\section{Kesimpulan}
Berdasarkan hasil pengembangan dan pengujian sistem, dapat disimpulkan bahwa:
\begin{enumerate}
    \item Sistem informasi peminjaman sarana dan prasarana kampus berbasis web telah berhasil diimplementasikan menggunakan bahasa pemrograman Go, basis data PostgreSQL (Supabase), dan metode Scrum, yang mengintegrasikan proses pengajuan, verifikasi Admin Sarpras, hingga validasi kehadiran Security secara terkomputerisasi.
    \item Fitur validasi jadwal berhasil mencegah bentrok peminjaman (\textit{double booking}) dan menyediakan kalender ketersediaan ruangan secara \textit{real-time} untuk pemantauan mahasiswa.
    \item Pengujian Black Box menunjukkan seluruh fungsi sistem berjalan sesuai spesifikasi. Pengujian unit menghasilkan code coverage 31,9\%, dengan modul inti mencapai tingkat keterujian di atas 75\%.
\end{enumerate}

\section{Saran}
Untuk pengembangan selanjutnya, disarankan untuk:
\begin{enumerate}
    \item Mengembangkan modul manajemen inventaris lanjutan yang mencakup monitoring kondisi aset (baik/rusak), pelacakan riwayat pemeliharaan, serta sistem penjadwalan \textit{maintenance} berkala untuk mendukung pengelolaan aset kampus yang lebih komprehensif.
    \item Mengembangkan fitur lanjutan: integrasi notifikasi WhatsApp Gateway, visualisasi statistik peminjaman, dan modul pemantauan kondisi aset.
    \item Menambahkan fitur evaluasi dan \textit{rating} kepuasan pengguna terhadap layanan peminjaman untuk mendukung peningkatan kualitas layanan secara berkelanjutan.
\end{enumerate}
